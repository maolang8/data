# 대시보드 웹호스팅 실습 - 서울시 따릉이 이용현황 대시보드

이 저장소는 서울시 따릉이 데이터셋을 활용한 대시보드 웹호스팅 실습 저장소입니다.

## 🚲 대시보드 주요 지표
- **총 이용건수**: 41,649,637건 (평일 75.4% / 주말 24.6%)
- **운영 대여소 수**: 2,824개소 (시간당 평균 310.40건)

## 📁 구성 파일
- `index.html`: 대시보드 메인 레이아웃 및 구조
- `style.css`: 글래스모피즘 다크 모드 스타일
- `script.js`: 동적 카운트업 애니메이션 및 Chart.js 시각화
